package "CM CAPACITY" {

class CMCapacityFormula {
  +formula : String = "CM_max = Σ activos + 0.5 * Σ KO"
}

class CMCapacityState {
  +allActiveStorage : double
  +allKOStorage : double
  +resultCMMax : double
}

note right of CMCapacityFormula
Capacidad máxima compartida del equipo.

CM_max = suma de storage de personajes activos
       + 0.5 * suma de storage de personajes KO
end note

CMSystem --> CMCapacityFormula
CMCapacityFormula --> CMCapacityState
}

package "CM GENERATION" {

class CMGainSource {
  +kind : CMGainKind
  +baseGain : double
  +finalGain : double
  +allowsModifiers : boolean
}

class BasicCMGeneration {
  +lightBase : double = 1/8
  +mediumBase : double = 1/4
  +heavyBase : double = 1/2
  +tempoBonusRatio : double = 1/3
  +failGain : double = 0
  +baseByWeapon(weight)
  +tempoBonus(base)
  +totalInTempo(base)
}

class CMModifierStack {
  +modifiers : List<double>
  +sumLinear()
}

note right of BasicCMGeneration
Generación base por básico:
- LIGHT  = 1/8
- MEDIUM = 1/4
- HEAVY  = 1/2

Si va en tempo:
Bonus_tempo = CM_base * 1/3
CM_total    = CM_base + Bonus_tempo

Si falla:
CM = 0
end note

note bottom of CMModifierStack
Los modificadores de generación
se aplican en suma lineal sobre la base:

CM_final = X + X*m1 + X*m2 + ...

Ejemplo:
X = 1
+20% y +10%
CM_final = 1 + 0.2 + 0.1 = 1.3
end note

CMSystem --> CMGainSource
CMGainSource --> BasicCMGeneration
CMGainSource --> CMModifierStack
}

package "VALID SOURCES" {

class CMSourcePolicy {
  +allowBasics : boolean = true
  +allowSkills : boolean = true
  +allowGadgets : boolean = true
  +allowReceiveDamage : boolean = true
  +allowDirectCombatEvents : boolean = true
  +allowPassiveDebuffs : boolean = false
}

note right of CMSourcePolicy
Fuentes válidas de generación:
- básicos
- habilidades
- gadgets
- recibir daño
- otros eventos directos de combate

No generan CM:
- debuffs pasivos
- efectos indirectos sin interacción directa
end note

CMSystem --> CMSourcePolicy
}

Si CM_actual + ganancia > CM_max,
el equipo entra en modo Clasical.
end note

}

package "KO INTERACTION" {

class CKKOHandler {
  +applyKOToStorage(unit)
  +recalculateAfterKO()
  +recalculateAfterRevive()
}

note right of CKKOHandler
Cuando un personaje entra en KO:
- su storage pasa a contribuir al 50%
- CM_max se recalcula inmediatamente

Si CM_actual > nuevo CM_max:
- CM_actual se ajusta al nuevo límite
end note

CombatantCMProfile --> CKKOHandler
TeamCMBar --> CKKOHandler
}

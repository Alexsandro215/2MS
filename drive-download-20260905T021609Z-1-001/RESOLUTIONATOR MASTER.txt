note right of HitService
<b>Hit check (canónico alineado a STATS MASTER)</b>

EVA_eff = def.evasionEffective

Si (att.accuracy + EVA_eff) <= 0:
   Hit% = HIT_MIN
Si no:
   Hit% = 5 + 90 * (att.accuracy / (att.accuracy + EVA_eff))

Hit% = clamp(Hit%, HIT_MIN, HIT_MAX)
hit  = RNG(0..100) < Hit%

Regla:
- fallo NO corta secuencia
- si falla un hit: no aplica daño/elemento/on-hit de ese impacto
- si la acción consume recurso, se consume aunque falle
end note

note right of DamageService
<b>computeDamageOneHit(a, atk, def, isDefendActiveThisHit)</b>

<b>0) CRIT (snap previo)</b>
critWouldApply = (a.skill.canCrit) AND (RNG(0..100) < atk.critPct)

<b>1) Daño bruto + penetración + reducción (alineado a STATS MASTER)</b>

Si PHYSICAL:
  D_raw = atk.physAtk * multSkill * multContext
  D_raw = D_raw * atk.damagePhysicalFinalMult

  PenArmor_eff = min(atk.penArmor, 0.8 * def.armorValue)
  Armor_f = max(0, def.armorValue - PenArmor_eff)
  Red_f = min(ARM_CAP/100, Armor_f / (Armor_f + 100))

Si MAGICAL:
  D_raw = atk.magAtk * multSkill * multContext
  D_raw = D_raw * atk.damageMagicalFinalMult

  PenRM_eff = min(atk.penResist, 0.8 * def.resistValue)
  RM_f = max(0, def.resistValue - PenRM_eff)
  Red_f = min(RM_CAP/100, RM_f / (RM_f + 100))

Si TRUE:
  D_raw = (atk.physAtk o atk.magAtk según skill/base) * multSkill * multContext
  D_raw = D_raw * atk.damageTrueFinalMult

  PenArmor_eff = 0
  PenRM_eff = 0
  Armor_f = 0
  RM_f = 0
  Red_f = 0

<b>2) DV% (daño verdadero separado)</b>
DV = clamp(a.skill.trueDamagePct, 0, 1)
D_true = D_raw * DV
D_norm = D_raw - D_true

<b>3) Reducción SOLO al normal</b>
D_red_saved = D_norm * (1 - Red_f)

<b>4) Aplicar crítico DESPUÉS de reducción</b>
D_red_candidate = (critWouldApply ? D_red_saved * 1.8 : D_red_saved)

<b>5) DEFEND anula crítico en el primer impacto</b>
Si isDefendActiveThisHit == true:
   D_red_final = D_red_saved
   critApplied = false
Si no:
   D_red_final = D_red_candidate
   critApplied = critWouldApply

<b>6) Total por hit</b>
D_final = max(0, D_red_final + D_true)

<b>applyDamageOneHit</b>
- D_final primero a shield, sobrante a HP
- DV NO ignora escudos
end note

note right of CMService

- Si invulnerable: no aplica
gainDef = 0.5 * cmGainPerHit(armaAtacante, false)
gainDef *= (DEFEND?2:1) * modificadores

<b>KO/Muerte</b>
- Al pasar a KO o DEAD: recalcular CM_max y clamp inmediato
end note

note right of ElementService
<b>Sistema elemental (canónico)</b>

- P_element = base n% + modificadores
- L1: 1 turno
- L2: 3 turnos

<b>Bloqueo por L2</b>
- Si target tiene L2 activo: se IGNORAN nuevos elementos

<b>Ventana por ciclo</b>
- Ciclo = turno completo de ambos equipos
- elementSuccessActorsThisCycle[targetId] = {actorIds con éxito}
- L2 ocurre si hay 2 éxitos en el MISMO ciclo por 2 PJs distintos al mismo target

<b>Regla L1 -> L2</b>
- Si hay L1 activo, se sigue intentando completar condición de L2
- Si no se cumple, se mantiene L1 hasta expirar

Reset ventana: al terminar el turno del villano
end note

note right of ItemService
<b>Curación rápida → Desgaste (canónico)</b>
- Cada 50% de HP_base restaurada (acumulada) => +1% desgaste

applyFastHeal(target, healAmount):
  hpCurrent = min(hpCurrent + healAmount, hpBase_eff)
  fastHealAccum += healAmount
  step = 0.5 * hpBase_eff
  while fastHealAccum >= step:
     fastHealAccum -= step
     fatiguePct += 0.01 (clamp 0..1)

<b>Comida/Consumible gratis</b>
- Solo ANTES de ofensiva
- 1 gratis por equipo (FOOD) y 1 gratis por equipo (ITEM), independientes
- Reset/recarga cada 3 turnos
- Reusar con CD>0 consume turno y NO resetea CD
end note

- Si llega el turno del villano con el objetivo en KO: puede ser REMATADO -> DEAD

<b>Última Bala</b>
- Post-daño, no altera daño
- No cuenta escudos, solo HP real
- Si HP_final <= umbral% de Vida Base => KO
end note

note right of CombatResolver
<b>resolveAction(a, teamAtk, teamDef, cycleState, ctx)</b>

0) derivedAtk = buildDerivedStats(actor, ctx)
   derivedDef = buildDerivedStats(target, ctx)

1) Validar LOCKs + costos + CDs + requisitos:
   si no permitido => cancelar

2) Resolver impactos (multi-hit)
   N = max(1, a.skill.multiHitCount)

   for i in 1..N:
     - Si target NO es targeteable (KO/DEAD): break

     - Hit-check:
         si a.skill.hitCheckPerHit:
            hit = rollHit(calcHitChance(derivedAtk, derivedDef))
         else:
            hit = hitPrecalculado

     - Si falla:
         consumir costos de la acción en el primer intento
         si a.skill.applyEffectsOnMiss == false: continue

     - Determinar DEF activo:
         isDefendActiveThisHit =
            (target.isDefending == true) AND
            (target.defendConsumedThisTurn == false)

     - Daño por hit:
         dmg = computeDamageOneHit(a, derivedAtk, derivedDef, isDefendActiveThisHit)
         applyDamageOneHit(target, dmg.D_final)

     - Consumir DEF si se activó:
         si isDefendActiveThisHit:
            target.defendConsumedThisTurn = true
            target.isDefending = false

     - CM:
         applyCMOnHit(a, dmg, teamAtk, teamDef)
         clampTeamCM(teamAtk)
         clampTeamCM(teamDef)

     - Pasivas on-hit / on-being-hit / on-crit:
         disparar según flags: hitSuccessful, critApplied, etc.

     - Elementos:
         si hit y skill.hasElement:
            tryApplyElement(actor, target, elementType, cycleState, ctx)

3) KO/Muerte:
   si HP<=0 => KO
   si KO llega al turno del villano y no fue atendido => remate -> DEAD

4) Última Bala:
   applyLastBulletIfAny(actor, target, derivedDef)

5) Si hubo KO/Muerte:
   recalcTeamCMMax() + clamp inmediato
end note

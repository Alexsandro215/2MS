note right of Gadget
REGLAS BASE FIJAS

• Cada aliado solo puede equipar 1 gadget
• Todos los gadgets tienen cooldown
• Los gadgets pueden mejorarse
• Un gadget solo puede activarse una vez por evento fuente
• La descripcion del gadget deja clara su naturaleza
end note

note right of GadgetUpgrade
MEJORAS POSIBLES

• ampliar cantidad de objetivos
• ampliar duracion
• aumentar valor
• reducir cooldown
• mejorar condicion
• agregar regla especial
end note

note right of OffensiveImpactRules
GADGET OFENSIVO DE IMPACTO

Si apunta ofensivamente a enemigos,
usa los principios del RESOLVER MASTER
salvo que el propio gadget diga lo contrario.

Esto puede incluir:
• evasion
• critico
• armadura o resistencia
• penetracion
• ruptura de defensa si la descripcion lo indica
end note

note right of ConditionalSystemRules
GADGET CONDICIONAL / SISTEMICO

No realiza chequeo de evasion.
No depende de impacto.
Se aplica directamente si trigger + condicion se cumplen.

Ejemplos:
• limpieza de estado
• drenado de CM
• aura de equipo
• activacion automatica
• creacion de items
• progreso de run
end note

note right of MultiHitRules
MULTI-HIT

• cada enemigo resuelve su propia secuencia
• puede que un enemigo reciba todos los impactos
  y otro solo algunos
• cada hit puede acertar o fallar individualmente
• cada hit puede critar individualmente
• cada hit puede recalcular segun la descripcion
end note

note bottom of PersistenceRules
PERSISTENCIA

Los modificadores dinamicos generados
dentro de la resolucion del gadget
solo existen durante esa resolucion,
salvo que el propio gadget diga lo contrario.

Tambien pueden existir efectos persistentes:
• durante 1 turno
• durante el combate
• durante la run
• hasta ser usados
end note

note bottom of ImplicitReadingRules
LECTURA IMPLICITA

Si la descripcion usa ideas como:
dispara / lanza / golpea / rafaga / balas / impacto
=> se interpreta como IMPACT y usa Resolver Master

Si la descripcion usa ideas como:
si ocurre X / al inicio del turno / drena / limpia / otorga
=> se interpreta como CONDITIONAL o SYSTEMIC
y aplica directo si se cumplen sus reglas
end note

note bottom of Desterradora
DESTERRADORA

Cada enemigo se resuelve por separado.
La penetracion escala solo con hits acertados.
La penetracion no persiste despues del gadget.
Se balancea por:
• dano base bajo
• evasion por hit
• armadura por hit
• cooldown
end note

note bottom of TostadoraQuemadora
TOSTADORA QUEMADORA

Abre la posibilidad de:
• crear items dentro de la run
• generar recursos consumibles
• persistencia hasta uso
end note

note bottom of LibretaDeApuntes
LIBRETA DE APUNTES

Abre la posibilidad de:
• progresion acumulativa por combate
• bonus persistentes durante la run
• gadgets ligados a participacion de personaje
end note
